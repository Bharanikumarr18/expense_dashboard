# Expense Dashboard 💰

A full-featured offline expense tracker built with Python.

## Features
- Add, edit, delete expenses
- Category & subcategory management
- Advanced filters (weekly, monthly, yearly, custom range)
- CSV & PDF export
- Dark UI
- Offline SQLite database
- Desktop launcher support (Ubuntu)

## Tech Stack
- Python
- Streamlit
- SQLite
- SQLAlchemy
- Pandas

## How to Run
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
